# Heart Disease Prediction

## Project Overview
This project uses Machine Learning to predict the presence of heart disease based on patient health-related features.

## Dataset
The project uses the UCI Heart Disease dataset.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib

## Machine Learning Algorithm
Logistic Regression

## Steps Performed
1. Loaded the Heart Disease dataset
2. Cleaned missing values
3. Converted data into numeric format
4. Split the dataset into training and testing data
5. Applied StandardScaler for feature scaling
6. Trained a Logistic Regression model
7. Generated predictions
8. Evaluated the model using:
   - Accuracy
   - Precision
   - Recall
   - Confusion Matrix
   - ROC Curve and AUC

## Output
The project generates:
- Confusion Matrix
- ROC Curve

## Project Files
- `heart_disease_prediction.py` - Main Python program
- `processed.cleveland.data` - Dataset
- `confusion_matrix.png` - Confusion Matrix graph
- `roc_curve.png` - ROC Curve graph

## Conclusion
The project demonstrates how Machine Learning can be used for binary classification of heart disease using Logistic Regression.
